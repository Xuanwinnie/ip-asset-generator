# IP Asset Generator

[English](README.md) · [繁體中文](README.zh.md)

固定 IP 角色素材生成 Skill，讓同一個角色可以在不同動作、場景與使用情境中持續保持一致。

它適合生成行動版活動頁主視覺、社群圖片、故事插圖、貼圖、透明背景角色素材與姿勢組合。Skill 會把角色身份鎖定，把動作、表情、場景、道具和素材格式作為可控變數，最後編譯成適合影像生成模型的完整 prompt。

這是一個提供給所有人使用的通用 Skill，不包含特定角色。每位使用者都可以提供自己的 IP 角色圖、角色描述或 IP Bible，生成屬於自己的系列素材。

## 快速開始

### 安裝到 Codex

```bash
git clone https://github.com/Xuanwinnie/ip-asset-generator.git \
  ~/.codex/skills/ip-asset-generator
```

### 安裝到 Claude Code

```bash
git clone https://github.com/Xuanwinnie/ip-asset-generator.git \
  ~/.claude/skills/ip-asset-generator
```

安裝後重新啟動對應的 AI 工具，並在對話中提供自己的角色參考圖或角色描述。

### 第一個生成請求

```text
使用我提供的 IP 角色，生成一張 1080x1920 的行動版活動頁主視覺。
角色正在雨天車站撐傘，上方保留標題空間。
維持角色臉型、招牌配件、色彩和畫風一致。
```

如果要建立自己的角色規格，可以先複製 [IP Bible 範本](references/ip-bible-template.md)，填入角色身份特徵，再搭配角色設定圖使用。

本 Skill 不會自動替使用者創造一個固定角色；角色內容、參考圖和品牌資產由使用者自行提供。

## 它解決什麼問題

一般影像生成常見的問題是：同一個角色每次生成後臉型不同、配件消失、身體比例漂移，或是換成不同場景後就不像原本的 IP。

這個 Skill 將 IP 拆成兩部分：

| 部分 | 說明 |
| --- | --- |
| 固定身份 | 臉型、五官、物種、身體比例、招牌顏色、永久標記與固定配件 |
| 可控變化 | 動作、表情、場景、季節、功能性道具、鏡頭角度與素材比例 |

角色身份必須穩定，畫面內容則可以變化。這樣能產生一組不同素材，同時讓使用者一眼辨認出它們來自同一個 IP。

## 支援的素材

| 素材類型 | 預設規則 |
| --- | --- |
| 行動版活動頁主視覺 | `1080x1920`、保留標題安全區、手機縮圖可辨識 |
| 社群方形貼文 | `1080x1080`、角色與短文案保持清楚層級 |
| 社群直式貼文 | `1080x1350`、保留上下裁切安全區 |
| 限時動態／短影音封面 | `1080x1920`、重要內容放在中央安全區 |
| 連結預覽圖 | `1200x630`、使用橫式構圖與中央安全區 |
| 透明角色素材 | 透明背景、完整輪廓、保留手腳與招牌配件 |
| 貼圖 | 單一動作或表情、乾淨剪影、不加入複雜背景 |
| 故事插圖 | 一個主要動作、一個情緒、一個具體場景 |
| 姿勢組合 | 維持相同角色比例、鏡頭距離、畫線和基準線 |

## 工作方式

```text
角色參考圖或 IP 描述
        ↓
辨識身份特徵與固定規則
        ↓
讀取動作、表情、場景與素材用途
        ↓
建立 IP Recipe Manifest
        ↓
套用對應素材構圖與安全區
        ↓
編譯五段式影像生成 Prompt
        ↓
生成並檢查角色一致性
```

每次生成前會先解析：

- `identity_anchors`：角色最重要的辨識特徵
- `fixed_rules`：不可改變的角色規則
- `allowed_variations`：允許變化的內容
- `action`：一個主要動作
- `emotion`：一個主要情緒
- `scene`：一個具體場景
- `asset_type`：行動版活動頁、透明素材、貼圖或故事插圖
- `output_requirements`：比例、透明度、裁切和文字安全區

## 使用範例

### 行動版活動頁主視覺

```text
讓我的 IP 角色在雨天車站撐傘，做成 1080x1920 的行動版活動頁主視覺。
角色放在畫面下半部，上方保留活動標題空間。
```

### 透明背景素材

```text
讓我的 IP 角色揮手，生成透明背景的完整角色素材。
保留招牌配件，不要文字和背景。
```

### 不同場景系列

```text
生成同一個 IP 的四張素材：
在森林煮飯、在海邊撿貝殼、在書店看書、在雨中散步。
維持角色臉型、服裝、比例和畫風一致。
```

### 姿勢組合

```text
生成一組角色姿勢：站立、坐下、跑步、驚訝、睡覺和拿咖啡。
維持相同鏡頭距離、角色大小、線條和基準線。
```

## 角色參考建議

為了提高一致性，建議準備一組 character reference pack：

- 正面、側面與四分之三角度
- 中性表情與常用表情
- 全身輪廓與多個動作
- 永久標記和招牌配件的特寫
- 核心色彩與材質參考

可使用 [IP Bible 範本](references/ip-bible-template.md) 整理角色資料。參考圖越完整，模型越容易在換動作與場景後保持身份。

## 一致性規則

Skill 會避免以下問題：

- 改變角色物種、年齡感、臉型或身體比例
- 移除或重複招牌配件
- 擅自增加永久標記
- 把角色變成泛用吉祥物表情
- 在透明素材中加入複雜背景
- 讓活動頁標題遮住臉部或重要特徵
- 姿勢組合中的鏡頭距離和角色大小不一致
- 加入未提供的角色、品牌、Logo 或活動資訊

## 限制

Skill 可以透過身份錨點、參考圖和檢查規則提高穩定性，但無法保證不同影像模型產生完全相同的臉部像素或細節。

如果生成結果仍出現身份漂移，優先補強 character sheet、永久特徵說明與多角度參考圖，而不是無限制增加 prompt 形容詞。
