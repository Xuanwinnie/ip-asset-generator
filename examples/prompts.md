# 公開使用範例

這些範例使用抽象的「我的 IP 角色」描述，使用者應替換成自己的角色名稱與參考圖。

## 行動版活動頁主視覺

```text
使用我提供的 IP 角色，在雨天車站撐傘，生成 1080x1920 的行動版活動頁主視覺。
角色位於下方，上方保留標題安全區。維持臉型、招牌配件、核心色彩和畫風一致。
```

## 社群系列

```text
使用同一個 IP 角色生成三張素材：
1080x1080 在森林煮早餐、1080x1350 在書店看書、1080x1920 在海邊散步。
每張依照自己的比例重新構圖，不要拉伸同一個版面。
```

## 透明素材

```text
生成同一個 IP 的六張透明背景角色素材：揮手、跑步、睡覺、驚訝、閱讀、拿咖啡。
維持相同角色比例、鏡頭距離、基準線和招牌配件，不要文字或背景。
```
